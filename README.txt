化学実験体験ゲーム 試作版

【起動方法】
1. フォルダ内の index.html をブラウザで開く
2. 「プレイする」から3つのゲームを好きな順番で遊ぶ
3. クリアするとスコアに応じてEXPを獲得
4. レベルとクリア状況は同じ端末・同じブラウザのlocalStorageに保存される

【ファイル】
index.html            トップページ
tekitei.html          滴定実験シミュレーション
 yosyumetiru_v2.html  指示薬クイズ
kousatsu_report.html  考察レポート作成
style.css             共通デザイン
 game-data.js         レベル・EXP・セーブ管理

【EXP】
各ゲームの最高スコアに対応したEXPのみ保存し、同じゲームの再プレイで無限にEXPを稼げないようにしています。
レベルアップに必要なEXPは Lv.1→2:100、以降50ずつ増加します。
最大Lv.10です。

【注意】
この版では元ファイルのビジュアルを参考に、外部画像がなくても動くようにビュレット・ビーカー・コック等をCSSで描画しています。
公開時はGitHub Pages等にフォルダ内のファイルをそのまま配置してください。
